# 手绘地图编辑器

只生成二维栅格地图和无类别物体的三维位置，无额外 Python 依赖。

## 启动

```bash
python3 editor_server.py
```

浏览器打开 `http://127.0.0.1:8765`，也可用 `--port` 指定端口。

## 使用

1. 设置地图宽高和分辨率，新建空白地图。
2. 拖动画障碍（黑色）、未知区域（灰色），用擦除工具恢复空闲（白色）。
3. 在左侧设置物体高度，选择“放置物体”并点击地图。调整高度只影响接下来放置的物体。
4. 如需修改已有物体，选择“选择物体”，点击目标后修改左侧高度。
5. 可撤销、删除物体、保存地图和重新打开地图。

长度单位为米。地图原点在左下角，+x 向右、+y 向上；栅格行从上到下保存。`#` 表示障碍，`?` 表示未知，`.` 表示空闲。每个物体保存 `id` 和 `position: [x, y, z]`。地图最多为 40×40 格。

导出文件只包含 `name`、`grid` 和 `objects`。旧场景文件可以打开，但只保留这些地图数据。障碍只有二维占据，不自动生成高度或三维遮挡体。

## 文件

- `editor.html`：地图编辑、绘制及导入导出。
- `editor_server.py`：本地页面服务。
- `tests/`：页面服务和前端编辑逻辑测试。

## 测试

```bash
python3 -B -m unittest discover -s tests -v
node tests/test_editor_ui.cjs
```

前端逻辑测试需要 Node.js，运行编辑器不需要。
