# 不同机器人如何接入

`base.py` 定义 RobotSource（只读采集）和 Navigator（可选运动控制）。
目前只有接口，没有任何具体机器人驱动。

后续适配器按通信方式实现，如 ROS topic/TF、厂商 SDK、离线录制回放。
同一通信栈的不同机器人优先用 profile 区分 topic、frame、深度单位、
相机外参、时间同步容差和超时，不为每个机器人复制算法。
机器人尺寸、安全余量继续使用 data/robot.json；相机标定继续使用正式相机配置。

RobotSource 负责 RGB/depth 对齐、去畸变、时间同步、位姿插值、单位与坐标转换。
输出采集时刻的 T_map_camera，不能使用推理返回时机器人的最新位姿。
不支持的能力应明确报错；读取传感器不隐式启动导航。

首个可执行适配器建议为 replay，用录制数据验证建图，再接现场机器人的通信栈。
具体 ROS 版本、传感器、SLAM 与导航服务待确认后实现，当前不假定设备能力。
