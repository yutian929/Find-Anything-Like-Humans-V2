# FALH-V2 实施进度与下一步

## 2026-10-24：锚点数优先、照片数其次

当前默认选择器已改为两阶段整数优化：全部目标合格覆盖是硬约束，先求最少锚点数，再固定该数量并在全部候选位置/方向中求最少照片数。旧加权贪心保留为独立基线，观察模型与采样保持不变。主结果 schema 5，候选 supports 仍为 schema 4；页面区分新方案静态热图与旧基线回放。

默认地图已从 **5 站14张降到 4 站10张**，28/28 物体合格覆盖。原候选池两阶段下界分别为 4 和 10，gap 均为 0。首次最优解在高密度复核中暴露一条遮挡误判关系，自动重选一次后保持 `(4,10)`，最终 280 个物体/照片组合的原采样与 96×96 合格分类一致。75 项 Python 测试及两组 Node.js 测试通过；观察候选生成仍约 56.58 秒，含复核重选的选择阶段约 16.13 秒，尚未开始观察模型加速。详见[本轮验收报告](lexicographic_anchor_selection_validation_20261024.md)。

最优性以两阶段证明状态及最终几何复核为准；超时可保留不劣于旧基线的可行解，不宣称已证最优。高密度复核失败时最多重选三次，只有达到原已证明成本才保留原候选池最优性；无法修复时退回通过高密度复核的基线，基线也失败则明确报告。实现依据见[修改与验收计划](lexicographic_anchor_selection_plan_20261024.md)。下方关于“当前加权选站”的描述与 5 站14张等数字为此前历史状态。

## 优化分支的新规则

2026-10-19，`refine/anchor-selection` 已实现[连续权重选点与逐物体热力图](anchor_selection_refine.md)：在遮挡采样前加入相机安装位姿、目标高度和视场约束的径向预筛；距离权重由内边界 1 线性降至外边界 0.5，再乘未遮挡比例，最终得分至少 0.5 才贡献有效票。入镜比例改为投影凸包的几何裁切面积比。选站改为未覆盖物体最佳合格得分叠加，支持单物体热图、总分图和贪心轮次回放，输出 schema 4。下方有关覆盖数优先、60% 未遮挡门槛和 schema 3 的记录均为改进前历史状态。

本分支当前默认地图结果为 5 个锚点、14 张照片，28/28 物体合格覆盖。最终 14 个动作的全部物体用 96×96 遮挡采样复核，合格分类一致；这不是全部候选的高密度重算或实拍识别保证。53 项 Python 测试及两组 Node.js 交互测试通过。实际运行和页面用法见上方新规则文档。

更新：2026-10-19。研究定义、两条候选生成路线及观察模型见[锚点选择文档](path_constrained_anchor_selection_v0_20261013.md)。当前 A1 已改为直接提取安全区域，移除前置全覆盖扫描路线；A2/A3 的物体驱动算法已通过 `falhv2/anchor_selector.py` 接入 `main`，独立于实验目录；下一步验证实际采集并改进照片选择。位置采样仅保留在 `experiment/anchor-candidate-drivers` 实验分支。详见[首轮实验报告](anchor_driver_experiment_20261014.md)。

## AABB 部分遮挡升级（2026-10-19）

- 编辑器新增三轴尺寸，保留中心高度；导出 `position` 与世界系 `aabb.min/max`，验证尺寸、底部与中心一致。旧点图不自动填尺寸。主画布用 XY 矩形、顶部高度色阶、底顶标签显示体积；选中后显示高度侧视条。
- `observation_model.py` 对完整目标投影采样，计算入镜比例、画面内未遮挡比例、可见像素面积。射线只比较目标前的最近交点；对临界门槛加密，质量为入镜率乘未遮挡率。
- 初始门槛为 80% 入镜、60% 未遮挡、400 px²，可在相机配置的 `observation_quality` 中覆盖。距离仍按相机光心到目标中心计算。实际参数写入输出，尚未现场标定。
- 保持覆盖数优先，平票比较最佳观察质量；不累加多个低质量方向完成覆盖。输出 schema 3，最终动作保存全部物体的指标与遮挡 ID，结果页面展示指标、Box 投影外框和缺口最佳已检查候选。
- 解析测试覆盖全遮挡、50% 遮挡、后方不遮挡、半入镜与像素不足；另验证平行射线、安装变换、完整候选对照、质量投票与 AABB CLI 导出。43 项 Python 测试和两组前端交互测试通过。
- 边界：AABB 视为实心；二维墙未自动转成三维几何；采样可能漏掉细遮挡，尚无解析误差保证；相机在实体内或目标跨相机平面时保守拒绝。当前不做多视角表面互补覆盖，导航占据仍由栅格独立提供。
