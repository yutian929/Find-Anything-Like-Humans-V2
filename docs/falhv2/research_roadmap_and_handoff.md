# FALH-V2 实施进度与下一步

更新：2026-10-14。研究定义、两条候选生成路线及观察模型见[锚点选择文档](path_constrained_anchor_selection_v0_20261013.md)。当前 A1 已完成，下一步先实现 A2 共用质量判断，再建立两条路线的候选与覆盖关系。

## 已完成

- [x] [地图编辑器](../../falhv2/README.md)：绘制栅格和无类别物体中心点，支持大图、缩放、平移、笔刷与矩形填充。
- [x] [A1 路径规划器](../../falhv2/path_planner.py)：只输入地图、机器人长宽与安全距离，采用 EDT 障碍膨胀、OpenCV 四连通标记、区间分解与往复扫描、A* 分区连接；不要求起终点。
- [x] 输出各区域安全格、连续四邻接路线、世界坐标航点、长度与转向统计；检查覆盖和净空，SVG 合并重复图元以减轻大图显示负担。断开区域分别输出，无安全格时明确失败。
- [x] 在 `main` 接入生产规划器，不依赖实验模块；使用 conda `test` 环境，A1 依赖 NumPy、SciPy、OpenCV。
- [x] 将用户地图和运行产物放入 Git 忽略的 `falhv2/outputs/`，备份目录 `outputs_/` 同样忽略。[最小导航示例](../../falhv2/examples/map.json)独立维护，12×12 格、0.5 m/格，物体集合为空。
- [x] 确定站位与定向拍摄分开计数，主要减少站位、其次减少照片；锚点数由算法输出，无预设数量预算。

A1 只验证可通行区域与路线，尚未验证物体视觉覆盖；区域与路线统计以对应输入和实际输出为准。

## A2 下一步：观察模型与候选生成

### 共用部分先实现

- [x] 实现 [D435i 标定导出脚本](../../falhv2/camera_parameters.py)，通过 conda `test` 中的 `pyrealsense2` 读取真机 RGB 1280×720、30 FPS 内参与畸变信息；读取结果保存于本地 outputs，与 `falhv2/config/camera.d435i.json` 使用相同精简结构；用户人工补全 `null` 标记的安装位姿和有效观察距离后，自行放入 config 作为默认参数。尚未验证实际图像采集，安装外参与有效观察距离待测量。
- [ ] 准备带稳定物体 ID、三维中心坐标的小场景；当前空物体导航示例只能用于零目标边界情况。
- [ ] 确认相机图像尺寸、内参或视场角、相对底盘的位置与朝向、去畸变状态、允许拍摄动作。首版固定安装高度和俯仰，通过底盘原地转向拍摄。
- [ ] 建立共用 `q(i,θ,o)`：动作可执行、相机坐标变换、前后关系、水平/垂直视场、距离及物体点高度。首版不要求物体尺寸或 AABB，不计算像素宽高；将结果称为视场和距离条件下的预计覆盖，不声称真实成像质量达标。
- [ ] 首版遮挡标为未评估；二维导航障碍和膨胀图不直接用于三维相机遮挡。
- [ ] 定义共用结果：站位 ID、区域与路径索引、拍摄方向、稀疏覆盖关系、逐物体支持集合、失败原因和内部配置。重合站位按物理位置去重。

### 两条待实现路线

| 路线 | A2 候选与覆盖构建 | A3 选择与优化 |
|---|---|---|
| 物体驱动，优先实现 | 每个物体反向生成合格观察位置/方向集合，与 A1 路径相交；首版离散表示，粗筛后用共用模型验证 | 动态投票 / 贪心集合覆盖，删冗余站位，再减少照片 |
| 位置驱动，对照实现 | 路径均匀或随机采样，枚举方向，正向检查能观察哪些物体，对缺口局部补点 | 使用同一求解器，便于比较候选生成差异 |

- [ ] 物体驱动：距离等保守界限筛出附近路径点，计算允许方向；不要用近似粗筛漏掉合格候选。
- [ ] 位置驱动：均匀采样作基线，随机采样记录抽样方式与种子；需要多个种子评估波动。此方法借鉴采样思想，不等同于生长运动树的 RRT。
- [ ] 对缺口局部加密位置和方向；记录最细间距、加密次数与资源限制。随机点多不构成全覆盖保证。
- [ ] 在相同位置、方向和质量模型下核对两条路线的 `q` 完全一致；输出覆盖缺口和诊断图。

当前 A1 遍历全部安全格中心，“路径约束”并不是稀疏骨架约束。改用骨架或改动扫描间距会改变候选空间，作为后续独立实验。

**A2 验收：** 用带物体的小场景人工/解析核对高度、安装偏移、视场边界、距离阈值、同站多方向及路径限制；所有输入物体保留在覆盖统计中，观察距离条件和未满足原因可追溯。A2 生成候选与预计覆盖，不输出未经 A3 求解的“最少锚点”。

## 后续顺序

- [ ] **A3 锚点选择：** 每个未覆盖物体对每站最多投一票，每轮选站后移除已完成目标的投票。先保持覆盖地删点，再减少拍摄方向；位置移动须重新验证路径、安全与质量。输出站位数、照片数、覆盖关系、缺口和求解状态。
- [ ] **A4 离线验证：** 候选生成对比固定路径、物体、质量模型和求解器，允许候选不同；求解器对比固定覆盖矩阵。报告候选规模、质量检查次数、耗时、覆盖、站位数与照片数，随机方法报告多种子波动，小案例用精确解核对。
- [ ] **B 静态真实实验：** 按锚点采集，独立检查实际图像质量并验证检索与找物。三维扫描的一站多方向、盲区补站作为参考，配准重叠仅在有实际需求时加入。
- [ ] **C 动态维护：** 物体分布变化后复核旧锚点，按需刷新记忆或补充站位，区分待采集和已采集状态。
- [ ] **D 长期评估：** 多轮变化、基线、消融与失败分析，再确定研究贡献。
