## 2. 实现

### 观察几何与采样分离

`observation_model.py` 将每批观察拆为 `_prepare_geometry()` 和 `_sample_occlusion()`。角点投影、投影外框、凸包及裁切面积、距离权重和遮挡体范围仅计算一次。粗采样与加密采样复用这些结果，原来的加密触发条件和采样位置不变。

完全入镜的凸包直接使用完整面积，省去四边裁切；距离权重批量计算。每个物体的八角点和各采样密度的归一化网格缓存。射线 slab 求交改为按三轴依次更新区间，保留除法、平行射线阈值和非负交点语义，避免多个三维临时数组及末轴归约。没有使用低精度或 fastmath。

### 候选几何门槛前置与诊断补算

候选阶段先计算入镜比例及画面内投影面积。入镜不合格或无遮挡面积上界已经不足时，跳过遮挡采样。本次跳过 **59,659 个物体—位姿**，全部输入目标均有合格观察，失败诊断补算数为 0。

快速路径未计算的遮挡指标使用 `None`，不伪造为零分。没有任何合格观察的目标会补算这些记录，以恢复原最佳失败诊断；补算时显式保留原位姿遍历顺序，避免平票位置改变。最终照片和基线照片始终完整计算所有目标的指标。新增统计为 `occlusion_skipped_pose_pairs`、`diagnostic_recomputed_pose_pairs`。

### 已证明成本下的修复搜索

首次两阶段求解仍保留原模型和证明过程。若高密度复核有缺口、基线通过复核，且原两阶段已证明最优，删除被否定的支持后先求原 `(锚点数, 照片数)` 下的可行解。

本次每次同成本搜索耗时分别为 **1.529、1.511、1.530 秒**，均找到 `(4,10)` 解，替代原来约 9.4 秒的两阶段重选。该搜索不声称产生新的最优性证明；删边不会扩大可行域，符合原成本且通过独立复核的解可以复用原候选池证明。

新增 `config.SAME_COST_REPAIR_TIME_LIMIT_S = 2.0`，每次搜索受此上限和全局 MILP 剩余预算共同限制。设为 0 可关闭。未找到解时继续完整两阶段重选；预算耗尽时回退通过复核的基线。未证明原成本最优时不走此捷径。零重试、失败/异常回退和最优性标签规则仍有效。

元数据新增 `optimization.high_density_verification.same_cost_searches`。成功修复的子记录使用 `repairs[].optimization.fixed_cost_feasibility`，首次两阶段的证明仍保存在主 `optimization.stage1/stage2`。主结果 schema 5、supports schema 4 不变。
